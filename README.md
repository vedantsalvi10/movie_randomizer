<h1 align="center">🎬 Movie Randomizer - Get a Random Movie Suggestion</h1>

<p align="center">
  <b>A simple movie suggestion app that fetches movie details using an API</b>  
</p>

---

<h2>📌 Description</h2>
<p>
  Movie Randomizer is a web app that suggests a random movie for your movie night. 
  It picks a movie from a predefined list of 20 movies and fetches its details using an API.
  The app then displays information such as the movie poster, actors, writer, release date, IMDb rating, plot, and awards.
</p>

---

<h2>🌟 Features</h2>
<ul>
  <li>✅ <b>Random Movie Generator</b> (From a predefined list of 20 movies)</li>
  <li>✅ <b>Movie Data Fetching</b> using an external API</li>
  <li>✅ <b>Displays Key Movie Details:</b></li>
  <ul>
    <li>🎥 Movie Poster</li>
    <li>🎭 Lead Actors</li>
    <li>✍️ Writer</li>
    <li>📅 Release Date</li>
    <li>⭐ IMDb Rating</li>
    <li>📖 Plot Summary</li>
    <li>🏆 Awards</li>
  </ul>
  <li>✅ <b>Styled Using CSS</b> for a clean UI</li>
</ul>

---

<h2>🛠️ Tech Stack</h2>
<ul>
  <li><b>Frontend:</b> HTML, CSS, JavaScript</li>
  <li><b>API:</b> OMDB API (or any other movie database API)</li>
</ul>

---

<h2>🚀 Installation & Setup</h2>

<h3>1️⃣ Clone the repository</h3>
<pre><code>git clone https://github.com/yourusername/movie_randomizer.git
cd movie_randomizer</code></pre>

<h3>2️⃣ Open <b>index.html</b> in a browser</h3>

<h3>3️⃣ Ensure API Key is Configured</h3>
<p>Make sure you have a valid API key for the movie database and set it in your JavaScript file.</p>

---

<h2>💡 How It Works</h2>
<ul>
  <li>🎲 Click on <b>"Generate Movie"</b> button.</li>
  <li>📌 A random movie is selected from a predefined list.</li>
  <li>🔍 The API fetches all details for that movie.</li>
  <li>🎬 Movie information is displayed on the screen.</li>
</ul>
